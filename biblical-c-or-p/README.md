# Biblical C or P

A library of biblical searches on key topics where Catholic and Protestant theology diverge — organized so a reader can look up a doctrine, see the scripture each side leans on, and study the question directly from the text rather than from secondhand argument.

**The goal is not to win a debate for either side. It is to find the truth.**

## Why this exists

Catholics and Protestants share the same Old and New Testaments (with one canon difference — see [`topics/canon-of-scripture.md`](topics/canon-of-scripture.md)) and agree on the core of the gospel: the Trinity, the incarnation, the death and resurrection of Jesus Christ, and salvation through him. Where they divide is a specific, well-defined list of doctrines. This library treats that list one topic at a time.

Each topic file follows the same format:

- **The question** — a plain statement of what's actually being disputed
- **Catholic position** — the scripture references Catholic theology draws on, with brief context
- **Protestant position** — the scripture references Protestant theology draws on, with brief context
- **Common ground** — what both sides actually agree on within the topic
- **Search terms** — additional passages and cross-references worth reading before forming a conclusion

No file tells you what to conclude. Read the references in their own chapters, not just the isolated verse — context is where most of these disputes are actually won or lost.

## A note on posture

These are old, serious disagreements among people who take the same book seriously. Approach the sources for both sides in good faith before deciding either is reading scripture carelessly. The strongest form of each position is the one worth engaging — not the weakest.

## Contributing

This is a reference library, not a polemic. Additions should keep the same balanced, reference-first format: primary scripture citations for both positions, minimal editorializing, and clear pointers for further reading (including each tradition's own confessional documents — the Catechism of the Catholic Church, the Westminster Confession, the Augsburg Confession, etc. — rather than only secondary commentary).
